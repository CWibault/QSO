# Q-Shaped Options for Hierarchical Reinforcement Learning

This folder contains a lightweight training entrypoint (`main.py`). All agent implementations are found under `qso/agents`.

## Getting Started

QSO requires **Python 3.9+**. To install the full dependencies, simply run `pip install -r requirements.txt`
